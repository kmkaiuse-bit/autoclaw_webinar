AI Agent 兩大方向

同一個目標，兩種截然不同的技術路徑

🖱️

方向 A：模仿人操作

Browser Automation
  • 控制瀏覽器或桌面軟件
  • 點擊、填表、截圖 — 像人一樣操作
  • 優點：無需 API，任何網站都能用
  • 工具：AutoClaw、Claude in Chrome
⚡

方向 B：API / Code

API Connection
  • 直接對接系統後台 API
  • 不依賴 UI，速度更快更穩定
  • 優點：可批量、可排程、不受介面變化影響
  • 工具：Gmail MCP、Calendar MCP、Custom Skills

💡 兩者可互補配合：AutoClaw 批量生成 PDF → Claude Desktop + Gmail API Skill 批量發送

知識點 2

寫好 Prompt 的方法論

TCREI 起稿第一版  ·  RSTI 卡關時自行迭代

TCREI
生成第一版 Prompt
Task — 你要什麼結果？目標是什麼？
Context — 背景、角色、使用場景
References — 給例子、格式樣本、參考資料
Evaluate — 跑一次，找出不對的地方
Iterate — 修改 Prompt，重新測試
RSTI
卡關時自行迭代
Revisit — 重看 Task，表達清楚了嗎？
Separate — 把複雜任務拆成多個步驟
Try — 換角度、換例子、換描述方式
Introduce constraints — 加限制條件：格式、長度、語言、禁止事項

💡 今天所有 Demo 的 Prompt 都是用 TCREI 設計的  ·  遇到問題就用 RSTI 改

Gmail 讀信 + 4象限分析

🖱️ Step 1 · 方向 A

瀏覽器讀信

  • Claude in Chrome 打開 Gmail
  • 逐封點開 → 讀取內容
  • 輸出 ✅ / 📖 / ❌ 分類摘要
⚡ Step 2 · 分析

Eisenhower Matrix

🔴 高重要＋高緊急
🟡 高重要＋低緊急
🔵 低重要＋高緊急
⚫ 低重要＋低緊急
【Step 1 — 先跑】 請幫我讀取 Gmail Web 收件匣中過去 7 天內的郵件。 逐封點開讀取，輸出摘要： [N] 寄件人：xxx 主旨：xxx 日期：xxx 摘要：（一句話） 建議：✅ 需要回覆 / 📖 已知悉 / ❌ 不適合 Agent 【Step 2 — 摘要完成後再跑】 根據剛才的收件匣摘要， 用 Eisenhower Matrix（4象限）重新分類： 🔴 高重要＋高緊急 → 今天必須處理 🟡 高重要＋低緊急 → 本週計劃完成 🔵 低重要＋高緊急 → 快速處理或委派 ⚫ 低重要＋低緊急 → 可忽略或刪除

⚠️

學生投訴

涉及紀律程序，必須由人親自處理，需要情感溝通與判斷。

❌ 必須人處理
🤝

合約續約談判

❌ 高決策成本

🎯 AI 處理低決策成本的事，高決策成本的事由你來。這就是 Human-in-the-Loop 的精髓。

📁 資料夾設定

建立你的 AI 工作資料夾

三條黃金法則 — AI 才能準確找到檔案、放對位置

📁 Demo_sharing/
├── 📁 01_會計_財務自動化/
├── 📂 Input_待處理單據/ ← 丟入原始檔
└── 📂 Output_核對總表/ ← AI 輸出到這裡
├── 📁 02_秘書_行政排班/
├── 📂 01_總表/
├── 📂 02_模板/
└── 📂 03_待發送通知/
└── 📁 03_老師_教案提煉/
├── 📂 Input_原始教案/
└── 📂 Output_教材包/
01

數字前綴排序

用 01_ 02_ 03_ 開頭，讓資料夾自動按順序排列，Prompt 描述時 AI 一眼認出步驟順序。

02

Input / Output 分開

原始檔放 Input，結果放 Output。AI 讀哪裡、寫哪裡一目了然，避免覆蓋原始檔。

03

避免空格與特殊符號

空格容易讓 AI 斷句出錯，改用 _ 底線連接。括號、斜線、星號等符號一律避免。
